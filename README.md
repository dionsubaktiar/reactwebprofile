# Dion Subaktiar - Web Profile & Portfolio

Portfolio modern dan profesional berbasis **Next.js 14**, **React**, **TypeScript**, dan **Tailwind CSS**. Repositori ini menampilkan profil pengalaman rekayasa perangkat lunak, sistem invoicing & billing interaktif, simulasi kredit kendaraan, serta pengelolaan artikel autentikasi.

## Fitur Utama Landing Page & Layanan

- **Enhanced Hero & About Section**: Ikhtisar profil profesional Dion Subaktiar sebagai Senior Software Engineer & System Architect.
- **Skills & Experience Section**: Visualisasi keahlian teknologi, backend microservices, DevOps, dan jejak karier.
- **Sistem Invoicing & Simulasi Finansial** (Aktif di Landing Page & `/invoicing-service`):
  - Kalkulasi otomatis: Subtotal, diskon fleksibel (persen / nominal), Dasar Pengenaan Pajak (DPP), dan PPN 11%.
  - Preset template siap pakai (Software Solutions, Hardware Servers, Armada Logistics).
  - Fitur cetak invoice / simpan ke PDF & salin ringkasan ke clipboard.
- **Simulasi Cicilan & Pengajuan Kredit**: Perhitungan angsuran berkala dan tenor pembiayaan.
- **Projects & Clients Section**: Portofolio proyek korporat dan partner yang telah dilayani.
- **Mini Playground & Activity Log**: Fitur interaktif langsung di halaman profil.

## Menjalankan Proyek Secara Lokal

1. Pastikan Anda telah menginstal Node.js (>= 18.x) dan npm / pnpm / yarn.
2. Clone repositori ini:
   bash
   git clone https://github.com/dionsubaktiar/reactwebprofile.git
   cd reactwebprofile
   
3. Install dependensi:
   bash
   npm install
   
4. Jalankan server pengembangan:
   bash
   npm run dev
   
5. Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.
